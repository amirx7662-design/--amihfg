# متجر الخدمات التقنية — NEXA

موقع عربي باتجاه RTL لعرض الخدمات التقنية والباقات والمنتجات الرقمية.

## التشغيل
افتح ملف `index.html` في المتصفح مباشرة، أو انشر مجلد `tech-services-store` باستخدام GitHub Pages أو أي استضافة صفحات ثابتة.

## محتويات النسخة الحالية
- صفحة رئيسية وأقسام الخدمات والمتجر والأسعار.
- معرض، مدونة، آراء عملاء، وأسئلة شائعة.
- نماذج حجز وتواصل ونشرة بريدية تجريبية.
- سلة تجريبية وبحث داخل الخدمات.

## قبل الإطلاق التجاري
- استبدل بيانات التواصل placeholder بمعلومات صحيحة.
- راجع أسماء الخدمات والأسعار وأضف تفاصيل النشاط الفعلية.
- اربط النماذج بخادم آمن وقاعدة بيانات.
- أضف تسجيل الدخول ولوحة تحكم فعلية عند إعداد backend.
- اربط بوابة دفع مناسبة بعد إعداد حساب التاجر والمتطلبات النظامية.

**تنبيه:** هذه نسخة واجهة أمامية فقط؛ النماذج والسلة لا تحفظ بيانات ولا تنفذ مدفوعات.
